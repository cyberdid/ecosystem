# ecosystem

Хаб персональної model-agnostic AI-екосистеми.

- **[AGENTS.md](AGENTS.md)** — конституція: принципи, шари, контракти (читати першим)
- **[MAP.md](MAP.md)** — карта вузлів: машини, сервіси, репозиторії, харнеси
- `skills/` — канонічні навички (SKILL.md), синкаються в усі харнеси
- `mcp/` — єдиний реєстр MCP-серверів
- `agents/` — ролі (orchestrator / worker / grader)
- `loops/` — реєстр автономних циклів (automation + skill + state + gate)
- `wiki/` — компільовані знання (LLM Wiki Pattern)

Модель — змінна деталь. Контракти й файли — постійні.
