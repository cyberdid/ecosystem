# Agents — ролі

Канонічні описи ролей, мапляться на модельні аліаси `eco-*` (див. `AGENTS.md` → Контракти → Модельний):

| Роль | Аліас | Задача | Принцип |
|------|-------|--------|---------|
| Orchestrator | `eco-orchestrator` | планування, декомпозиція, делегування | найрозумніша модель, мало викликів |
| Worker | `eco-worker` | масова робота (код, читання, драфти) | локальна/дешева, багато викликів |
| Grader / Verifier | `eco-grader` | перевірка чужої роботи за рубрикою | ОКРЕМИЙ контекст від maker'а; бачить лише артефакт + рубрику |

Правило maker/checker: той, хто зробив, — не той, хто перевіряє. Завжди.
